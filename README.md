## Don't Open The Upstairs Door

Demo: https://lwhsbg.itch.io/dont-open-the-upstairs-door

# What It Is

It is a short horror and mystery visual novel made using renpy in which you visit your childhood friend after three years in his house just to find out that he has been living in strange circumstances.

# Why I Made It

I made it as I wanted to try a certain type of branched endings where getting certain choices could make you reach the ending faster hence giving more exploration routes, and also this concept was very interesting.

# How I Made It

Tech stack:

- Renpy

# What I Struggled With & What I Learnt
The thing i Struggled with was actually making different files for different scenes as I had never done that and just used to compile a million lines in one file so thats a very cool thing and the game itself was very simple so i did not have much issues regarding it. Overall making this project was very fun.
